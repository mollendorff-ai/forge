### Changed

- **Forge is worked on in four lanes, and a change's changelog entry is a file of its own** (roadmap E-LANES). Several agent sessions work on Forge at once; each now works in one lane (engine, manual, features, architecture) with its own roadmap in `.asimov/roadmap/`, as `AGENTS.md` and `.asimov/project.yaml` say (asimov 3.6.0 reads the lanes). A change's changelog entry is a new file in `changelog.d/`, which `make changelog` collects into `CHANGELOG.md` with scriv when a release is made, so two pull requests no longer edit the same lines. `docs/SESSIONS.md` has how a session works here, imported by `CLAUDE.md`. `validation/repo`'s `lanes` check holds it: every lane has its roadmap, no item id is in two places, each fragment has only the four headings, and nothing is written under `[Unreleased]` by hand.
